Convolutional Neural Network (CNN)

Project: Handwritten Digit Classification (MNIST)

This project uses a Convolutional Neural Network (CNN) to recognize handwritten digits from 0 to 9.

Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

Model Architecture

- Convolutional Layer (Conv2D)
- Max Pooling Layer
- Flatten Layer
- Dense Layer
- Dropout Layer
- Softmax Output Layer

Dataset

MNIST handwritten digit dataset containing 28 × 28 grayscale images.

Model Evaluation

- Accuracy
- Loss
- Confusion Matrix
- Classification Report

Files

- CNN.ipynb – Complete implementation and training.
- mnist_cnn_model.keras – Saved trained model.

Objective

To classify handwritten digits using deep learning and understand how CNNs extract image features
